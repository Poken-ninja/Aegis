# Rules of Engagement

AEGIS is restricted to synthetic, authorized experimentation.

## Allowed

- synthetic network configurations
- synthetic hosts
- synthetic vulnerabilities
- simulated Red actions
- simulated Blue actions
- deterministic and stochastic simulation
- automated experiments against the simulator
- quantitative analysis of simulator results

## Not part of the project

- unauthorized network access
- real exploitation
- credential theft
- malware
- phishing
- persistence on real systems
- destructive actions against real systems
- testing systems without explicit authorization

## Research integrity

AEGIS will:

- record seeds and configuration identifiers
- distinguish simulator errors from experimental outcomes
- test the simulator before trusting RL results
- report negative results
- avoid claiming real-world effectiveness from simulation alone
- distinguish prior work, framework capability, engineering work, research contribution, and hypotheses
- preserve reproducibility information for experiments
